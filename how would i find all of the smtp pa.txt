To find all SMTP packets sent from a specific source IP address in Wireshark, follow these steps:

---

### **Step-by-Step Guide:**
1. **Open Wireshark and Load the Capture File**:
   - Launch Wireshark.
   - Go to **File > Open** and select the capture file (PCAP) you want to analyze.

2. **Apply a Display Filter**:
   - **Method 1 (GUI)**:
     - Click the **Filter** button (top-left) or go to **View > Show/Hide > Filter**.
     - In the filter bar, type the following expression:
       ```plaintext
       protocol:smtp and src == [Your_IP_Address]
       ```
       - Replace `[Your_IP_Address]` with the actual IP address you want to filter (e.g., `192.168.1.100`).
     - Click **Apply**. Wireshark will display only the matching packets.

   - **Method 2 (Command Line)**:
     - Use the `-i` option to run Wireshark with a command-line filter:
       ```bash
       wireshark -i "protocol:smtp and src == [Your_IP_Address]"
       ```
     - Replace `[Your_IP_Address]` with your target IP.

3. **View the Results**:
   - The filtered packets will appear in the main window. You can scroll through them, sort by **Time**, **Protocol**, or **Source/Destination** columns as needed.

---

### **Key Filter Syntax Explained:**
- **`protocol:smtp`**: Filters for packets identified as part of the SMTP protocol (case-insensitive).
- **`src == [IP Address]`**: Restricts results to packets with the specified source IP address.

---

### **Additional Tips:**
- **Check Column Headers**:
  - If unsure about the protocol or IP fields, click the column header (e.g., "Protocol" or "IP/ICMP") to see the actual values.
- **Export Results** (Optional):
  - To save the filtered packets, right-click a packet and select **Export > Export packets as...**. Choose a format (e.g., `.pcap` or `.txt`) and location.
- **Dynamic filtering**:
  - If your target IP is in a list (e.g., from a file), use `src in {IP1, IP2, ...}` (replace with your IPs in curly braces).
- **SSL/TLS Traffic**:
  - Ensure the capture file is decrypted (if encrypted) before applying filters. Use **Statistics > Decryption** to check and decrypt traffic.

---

### **Example Filter for IP 192.168.1.100**:
```plaintext
protocol:smtp and src == 192.168.1.100
```

This will show all SMTP packets originating from the IP address `192.168.1.100`.
